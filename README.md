# DevTrack 🐛

> 개인용 경량 이슈 트래커 웹앱 — 바이브코딩(Vibe Coding) 실습 프로젝트

## 프로젝트 개요

DevTrack은 소규모 개인 개발 프로젝트에서 발생하는 버그 및 작업 이슈를 간편하게 추적·관리하기 위한 웹 애플리케이션입니다.  
본 프로젝트는 **AI 보조 개발(바이브코딩)** 방법론을 적용하여, 요구사항 분석부터 품질 관리에 이르는 소프트웨어 개발 프로세스 전반을 실습하는 것을 목적으로 합니다.

## 기술 스택

| 구분 | 기술 |
|------|------|
| Frontend | React 18 (Vite) |
| 상태 관리 | React useState / useReducer |
| 데이터 저장 | localStorage |
| 스타일링 | CSS Modules |
| AI 도구 | Claude (Anthropic) |
| 형상 관리 | Git / GitHub |

## 주요 기능

- ✅ 이슈 생성 (제목, 설명, 우선순위, 태그)
- ✅ 이슈 상태 관리 (Open → In Progress → Resolved → Closed)
- ✅ 필터링 (상태별, 우선순위별)
- ✅ 이슈 수정 및 삭제
- ✅ 로컬 스토리지 영속성

## 바이브코딩 방법론

본 프로젝트에서 AI(Claude)를 활용한 방식:
1. **요구사항 도출**: AI와의 대화를 통해 기능 목록 구체화
2. **코드 생성**: 컴포넌트 단위로 AI에게 구현 요청
3. **리뷰 및 수정**: 생성된 코드를 직접 검토하고 맥락에 맞게 수정
4. **디버깅**: 오류 발생 시 AI와 함께 원인 분석
